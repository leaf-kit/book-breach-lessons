# 출처 유지보수 목록

기준일 2026-10-05.

> **공개를 막는 항목은 없습니다.**
> 본문에서 확인하지 못한 자리는 전부 **빈칸으로 두고 어디서 찾는지만 적는 방식**으로
> 정리했습니다(2026-10-05 결정). 아래는 **출처를 더 좋은 것으로 올리는 작업**이고,
> 끝나도 책의 서술은 대부분 그대로입니다.

## 두 종류입니다

| 종류 | 무엇 | 끝나면 |
|---|---|---|
| **승급** | 2차 출처를 1차로 교체 | 라벨이 ⚠️ 에서 ✅ 로 올라갈 수 있습니다 |
| **갱신** | 날짜가 붙은 사실이 바뀌었는지 확인 | 바뀌었으면 판 번호를 올립니다 |

## 고칠 때 지킬 것

1. `facts.yaml` 을 먼저 고칩니다. **`checked_date` 와 `label` 을 반드시 갱신합니다**
2. 그다음 `grep -rn "F-0NN"` 으로 본문의 모든 인용을 찾습니다. **한 곳만 고치지 마십시오**
3. 라벨이 ⚠️ 에서 ✅ 로 바뀌면 "보도에 따르면" 같은 단서를 떼도 되는지 봅니다
4. 서술이 바뀌면 `appendix/e-changelog.md` 에 적고 판 번호를 올립니다
5. **답을 못 찾으면 못 찾았다고 적습니다**

# 1. 승급 — 2차를 1차로

## 1-1. 2026 금융권 연쇄 해킹 (F-001 ~ F-008)

- [ ] 완료 ( )

**지금** 언론 보도. **가야 할 곳** 금융위원회, 금융감독원, 금융보안원 보도자료,
개인정보보호위원회 처분 공개.

**확인할 것** — 조사가 끝났는가. 피해 규모가 바뀌었는가.
유출 항목이 기관별로 구분되어 발표됐는가. 공격 주체에 대한 당국 표현이 바뀌었는가.

**주의** — 이 사건은 **본문 열두 곳**에서 인용됩니다. 수치가 바뀌면 전부 찾아야 합니다.
F-003 의 claim 에 "어느 항목이 어느 기관에서 나왔는지 보도에서 구분되지 않는다"를
적어 두었습니다. 공식 발표가 구분해 주면 그 문장을 지웁니다.

## 1-2. MGM 과 Caesars (F-054 ~ F-056)

- [ ] 완료 ( )

**지금** 언론 보도와 공격자 측 주장. **가야 할 곳** SEC EDGAR 의 2023년 8-K.

**확인할 것** — 초기 침투 경로와 "10분 통화"가 공시에 있는가.
Caesars 의 몸값 1,500만 달러가 공시에 있는가.

| 답 | 무엇을 하나 |
|---|---|
| 공시에 있음 | "보도에 따르면"을 떼고 ✅ 로 |
| 공시에 없음 | **지금 서술 유지.** 단서가 맞다는 확인이 됩니다 |

## 1-3. 2011 농협, 2014 카드 3사 (F-040 ~ F-044)

- [ ] 완료 ( )

**지금** F-043 은 위키(3차), 나머지는 언론.
**가야 할 곳** 판결문, 금융위 의결서, 당시 수사 발표.

**주의** — 농협 사건의 공격 주체에는 당시 이견이 있었습니다.
1차 자료를 찾아도 **이 책은 주체를 단정하지 않습니다.** 구조만 봅니다.

## 1-4. NIST PQC (F-110, F-112)

- [ ] 완료 ( )

**지금** 2차 해설. **가야 할 곳** `csrc.nist.gov` 의 FIPS 203, 204, 205 와 IR 8545.

내용이 같으면 F-112 를 ✅ 로 올립니다.

## 1-5. OWASP Agentic Top 10 (F-074, F-075)

- [ ] 완료 ( )

**지금** 벤더 블로그. **가야 할 곳** `genai.owasp.org` 원문 PDF.

**확인할 것** — ASI01 ~ ASI10 의 공식 항목명이 `part2/05-rules-global.md` 의 표와 같은가.
발표일과 EchoLeak 인용이 맞는가.

## 1-6. 슬롭스쿼팅 연구 (F-078, F-079)

- [ ] 완료 ( )

**지금** F-078 은 위키, F-079 는 2차 인용.
**가야 할 곳** USENIX Security 2025 원논문, 용어 제안자의 원문.

**주의** — F-079 의 수치는 **본문 세 곳**(1.4, 3.2, 4.10)에서 같이 쓰입니다.

## 1-7. 개인정보 보호법 조문 (F-090, F-092, F-093)

- [ ] 완료 ( )

**지금** 로펌 브리핑과 신구조문 대조 자료.
**가야 할 곳** 국가법령정보센터의 법률 제21445호, 대통령령 제36671호.

**확인할 것** — 72시간 통지 조문(시행령 제39조의2 제1항, 제39조의3 제1항)과
CPO 조항의 번호가 맞는가.

**주의** — 72시간 조문은 **본문 네 곳**(2.3, 2.4, 4.3, 그리고 부록 B)에서 인용됩니다.
네 곳이 같은 번호를 써야 합니다.

**범위 밖** — 과징금 요건 해석은 검증하지 않습니다. 아래 「다루지 않기로 한 것」 참조.

| 표준 현재 판 번호 | 적지 않음 | 2026-10-05 | 적는 순간 낡는다. 고르는 기준만 준다 |
| 비밀번호 저장 알고리즘 특정 | 기준만 제시 | 2026-10-05 | 특정하면 낡는다 |
| TLS 유효기간 단축 일정 | 방향만 적음 | 2026-10-05 | 단계가 바뀐다. 결론(자동 갱신)은 같다 |
| 딥페이크 사건 사례 | 싣지 않음 | 2026-10-05 | 1차 출처 미확인 |

**공통 원칙** — 조문 해석, 각 조직의 해당 여부, 자주 바뀌는 버전과 일정은
책이 가질 수 없는 정보입니다. **어디를 봐야 하는지까지가 책의 몫입니다.**
